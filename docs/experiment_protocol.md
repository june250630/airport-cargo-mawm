# 实验协议草案

本文档用于在进入VMAS和像素JEPA前固定最小实验方法，避免一边查看测试结果一边修改参数。

## 1. 四格诊断矩阵

| 动力学 | `task`代价 | `shaped`代价 |
|---|---|---|
| 真实仿真器 | Oracle-Dynamics / Task | Oracle-Dynamics / Shaped |
| 学习模型 | Learned-Dynamics / Task | Learned-Dynamics / Shaped |

- `task`：货物到目标距离、碰撞、动作代价和成功奖励；
- `shaped`：在`task`基础上增加两车到耦合半径的违反量、两车距离平衡，以及“距离满足且动作非零同向”的耦合提示；
- shaped代价不能写入脚本专家的具体站位、路径或动作序列；
- Oracle使用全局状态和真实动力学，只是搜索诊断，不是部署方法或数学最优上界。

## 2. 公平比较条件

同一实验组必须使用相同的：

- 环境初始状态和环境随机种子；
- 独立记录的CEM搜索随机种子；
- 80步真实环境预算；
- 动作范围`[-1, 1]`；
- 成功半径、碰撞定义和终止条件；
- CEM规划时域、样本数、精英数、迭代数和每步重规划频率；
- warm-start规则。

当前开发预算为：

```text
horizon = 20
samples = 256
elites = 32
iterations = 4
```

正式论文至少增加中等和大预算消融，例如`1024×5`与`4096×10`。同时报告每次重规划的动力学调用次数，不能只比较墙钟时间。

## 3. 数据划分

- 训练集、验证集和测试集按完整`scene_id`划分；
- 不允许把同一场景的相邻帧随机拆进训练集与验证集；
- 代价权重、规划预算和停止条件只在验证种子上选择；
- 测试场景和测试种子冻结后不得用于调参。

建议第一阶段：

```text
训练场景：1000
验证场景：100
测试场景：50
环境测试种子：固定50个
CEM搜索种子：每个环境场景3个
模型训练种子：至少3个
```

## 4. 必报指标

- 成功率及置信区间；
- 成功所需步数；
- 最终和最小货物目标距离；
- 首次耦合时间、耦合步数及耦合比例；
- 碰撞次数和发生碰撞的episode比例；
- 累计环境回报；
- 每回合规划时间；
- CEM动力学评估次数；
- 模型预测代价与真实执行代价之差，即model exploitation gap。

## 5. 决策校准实验

训练至少3个不同初始化的世界模型。使用模型集成对同一候选动作序列进行预测，以成员间分歧作为认知不确定性：

```text
普通CEM：uncertainty_weight = 0
校准CEM：uncertainty_weight > 0
```

不确定性权重只在验证集选择。测试集报告任务性能与校准指标，不能只报告成功率。

## 6. 分布外条件

保持训练数据不变，分别改变：

- ULD质量或可推动阈值；
- 地面摩擦；
- 障碍物位置；
- 单个牵引车动作衰减或失效；
- 通信或动作延迟；
- 未见过的机场布局。

比较普通CEM与校准CEM在安全性、保守性和任务成功率上的变化。
